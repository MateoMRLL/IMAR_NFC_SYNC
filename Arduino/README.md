# Arduino Folder

## Disclaimer

This file contains both way to implement Arduino code in the **ESP32**.
Make sure to read the guide in Readme Folder [Platformio](../Readme/Platformio%20Extension.md).

## More informations

> If you are using Platformio setup make sure to change `include/config.h` : it contains some WIFI credentials and Raspberry IP address.

> If you are using Arduino classical setup, just copy paste the content of the file in your brand new Arduino project and change WIFI credentials and Raspberry IP address.
